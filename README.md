# 📢 공지사항 웹 (Firebase)

관리자가 공지를 올리면, 누구나 웹·휴대폰에서 볼 수 있는 앱입니다.
소통은 네이버 카페로 연결됩니다.

---

## 📁 파일 구성

| 파일 | 하는 일 | 고쳐야 하나요? |
|------|---------|:---:|
| `index.html` | 유저가 보는 공지 화면 | ✕ |
| `admin.html` | **관리자가 공지 올리는 화면** | ✕ |
| `config.js` | **설정 (카페주소·Firebase)** | ✅ **여기만!** |
| `styles.css` | 디자인 | ✕ |
| `app.js` / `admin.js` | 동작 로직 | ✕ |
| `firestore.rules` | 보안 규칙 | ✕ |
| `firebase.json` | 배포 설정 | ✕ |

> 💡 지금 바로 `index.html`을 열어보면 **데모 화면**이 보입니다.
> 아래 순서대로 하면 실제 클라우드와 연결됩니다.

---

## 🚀 따라하기 (약 20분)

### 1단계 — Firebase 프로젝트 만들기 (무료)
1. https://firebase.google.com 접속 → 로그인 → **콘솔로 이동**
2. **프로젝트 만들기** → 이름 입력 (예: `notice-app`) → 계속
3. Google 애널리틱스는 꺼도 됩니다 → **프로젝트 만들기**

### 2단계 — 데이터베이스(Firestore) 켜기
1. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
2. 위치는 `asia-northeast3 (서울)` 선택
3. **프로덕션 모드**로 시작 → 완료

### 3단계 — 보안 규칙 넣기
1. Firestore 화면 상단 **규칙** 탭 클릭
2. `firestore.rules` 파일 내용을 **전부 복사해서 붙여넣기** → **게시**

### 4단계 — 관리자 로그인 켜기
1. 왼쪽 메뉴 **빌드 → Authentication** → **시작하기**
2. **이메일/비밀번호** 선택 → 사용 설정 → 저장
3. **Users** 탭 → **사용자 추가** → 관리자 이메일·비밀번호 입력
   (이게 공지를 올릴 때 쓰는 관리자 계정이에요)

### 5단계 — 설정값 복사하기
1. 왼쪽 위 ⚙️ **프로젝트 설정**
2. 아래로 내려 **내 앱** → **</>** (웹) 아이콘 클릭
3. 앱 닉네임 입력 → 등록
4. 화면에 나오는 `firebaseConfig` 값을 복사

### 6단계 — config.js 채우기
`config.js`를 열어서:
- `cafeUrl` → 여러분의 네이버 카페 주소
- `firebase: { ... }` → 5단계에서 복사한 값으로 교체

### 7단계 — 인터넷에 올리기 (배포)
컴퓨터에 터미널이 있다면:
```bash
npm install -g firebase-tools
firebase login
firebase init hosting     # public 폴더는 현재 폴더(.) 선택, SPA는 No
firebase deploy
```
끝나면 `https://프로젝트이름.web.app` 주소가 나옵니다.
이 주소를 사람들에게 공유하면 됩니다! 🎉

> 터미널이 어렵다면 **Netlify Drop**(netlify.com/drop)에 이 폴더를
> 통째로 끌어다 놓기만 해도 바로 웹 주소가 생깁니다.

---

## ✍️ 공지 올리는 법
1. `배포주소/admin.html` 접속
2. 4단계에서 만든 관리자 이메일·비밀번호로 로그인
3. 제목·내용 쓰고 **공지 올리기** → 끝!
4. 유저 화면(`index.html`)에 바로 나타납니다.
